# .github

Default community files for storytold repositories. A repository that has no file of its own uses the one here.

- `.github/pull_request_template.md`: the pull request description, in the order craft-contrib's [standards/pull-requests.md](https://github.com/storytold/craft-contrib/blob/main/standards/pull-requests.md) sets. It changes with that document: wording fixes are ordinary pull requests, and a change to the order or the sections follows the document's own process (RFC-0013 point 5).
